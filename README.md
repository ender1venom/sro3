# FORMA — СРО 3

Интерактивное офисное пространство в 3D и AR.

**Автор:** Новосёлов Илья Фёдорович.

- Сайт: https://ender1venom.github.io/sro3/
- QR-код: https://ender1venom.github.io/sro3/qr.html
- Отчет: [СРО 3](Отчет_СРО_3_Новосёлов.docx)

## Запуск

Сборка не нужна. Выполните `python -m http.server 8080` в каталоге проекта и откройте http://localhost:8080. Для мобильного AR используйте опубликованный HTTPS-сайт.

## Возможности

Вращение и масштабирование модели, сброс камеры, три интерактивные зоны, три цвета кресла, создание и скачивание QR-кода. Адаптивная верстка для компьютера и смартфона.

## Структура

`index.html`, `styles.css`, `app.js` — основной интерфейс. `office.glb` — исходная модель. `qr.html`, `qr.js` — страница QR-кода. `vendor` — model-viewer 4.1.0 и QRCode.js 1.0.0 с лицензиями. Шрифт Manrope загружается из Google Fonts с системным запасным шрифтом.

## Проверки и ограничения

Проверены загрузка GLB в Edge, выбор кресла, реальное изменение материала, генерация и скачивание QR, отказ от некорректного HTTP-адреса и отсутствие горизонтальной прокрутки при ширине 390 px. GitHub Pages отвечает HTTP 200.

AR требует совместимого устройства и разрешения камеры. Проверка трекинга на физических iOS/Android устройствах не выполнялась. Нативные Scene Viewer и Quick Look могут не отображать HTML-метки и изменения материалов веб-страницы. Исходная модель содержит цветовые PBR-материалы без отдельных Normal-карт.

GitHub Pages публикует корень ветки `main`.
